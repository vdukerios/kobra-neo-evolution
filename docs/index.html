Kobra Neo Evolution · screen simulator (KNE 1.0.0)

To run a real print: click → Print → pick a file → choose Full or Express → Print. Shortcut: the "Printer state" buttons in the panel.

Only controls: one knob (turn left/right) and its click. Shortcuts: ← → = turn · Enter = click · mouse wheel over the screen = turn.
Hold the click (or Enter) 0.8 s = help for the selected item.
