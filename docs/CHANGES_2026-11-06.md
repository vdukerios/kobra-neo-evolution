# Source candidate update — 6 November 2026

**Not compiled or tested on the printer. No firmware binary is included.** An earlier Keil/Arm Compiler 5 build booted; that result does not validate the changes below. The existing 1.0.0 source-release tag remains historical; the latest candidate is on `main`.

## Menus and display

- Configuration is reduced to seven groups: Calibration, Materials, Motor mode, Preferences, Saved settings, Information and Service. Maintenance is available once in the main menu.
- Removed overlapping ordinary paths for leveling, homing, cooling, saving, calibration and printer identity. Home shortcuts are an explicit exception: they preserve their original menu entries.
- Added colorful Home shortcuts for preheating, loading, unloading, leveling/centering and editing Z offset. Existing print pages remain available while printing.
- Shared dark cards, colors and selection styling across menus and value editors. Wheel-operated confirmations show the actual action names. The simulator shows seven list rows; native text keeps the existing font and is not pixel-identical to the demo.
- The name **Z offset** is fixed in both interface languages. Firmware website/source metadata now uses the canonical HTTPS project URL; the on-screen address is split into two readable lines.

## Filament, calibration and settings

- Loading and unloading always ask for material and nozzle temperature, with PLA selected initially. The nozzle heats before extrusion, which continues until the wheel is clicked.
- Completing a load stops extrusion, returns Home and applies the selected bed/fan recipe while keeping the chosen nozzle temperature. Cancelling warm-up or unloading does not trigger it; no print file is started.
- Filament and temperature calibration use guided steps. The simulator keeps physical measurements and thermal tuning results explicitly simulated.
- Settings save, reload and factory reset are separated; destructive changes require confirmation. Firmware EEPROM version K10 triggers factory defaults when upgrading from the older Nuclear layout; back up and recheck calibration before any future installation.
- Motor current checks are shared by menu entry, commands and restored settings. The 400–1200 mA project bounds are not electrical certification.
- Bed leveling preserves valid prior data when cancelled and reports failure to print preparation. Temperature targets and preparation failure handling were reviewed; physical checks are still required.

## Maintenance

- Resetting the axis reminder no longer also resets the belt reminder.
- The final partial interval is retained when a print stops or finishes. Preparation counts; pause and idle do not.
- Counters are independent of normal settings and save at job end/stop, reminder reset, and hourly checkpoints. A power cut during a job can lose the time since the last save; stored totals survive normal shutdown.

## Evidence and limits

- 88 model cases passed; all 42 generated screens reached in 12 language/state/settings scenarios; 11 injected duplicate regressions rejected.
- 1,382 offscreen renderer views had no text beyond the 320 x 240 canvas; representative images were inspected. This is not browser automation or a physical display test.
- Conditional source blocks and JavaScript syntax were checked. A legacy conditional opening was restored to match its retained `else`/`endif`.
- No Keil/GCC compiler, printer USB connection, flashing or physical calibration was run. Hardware startup, memory use, screen speed and thermal/mechanical behavior remain pending.
